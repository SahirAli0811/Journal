## Introducing Journal for Hackclub ##
## Here you can connect you Hackatime and Github, and create a journal book where you select the Hackatime project and Github repo and everytime time is recorded it would update and ask you what you did, you can write whatever you want in normal format and not in .md format, it would itself format it in .md format and would save it as your journal, you can also see the stats of the time you spent on it and the projects you worked on and would publish and update on Github repo
